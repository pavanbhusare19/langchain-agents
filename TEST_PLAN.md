# Test checklist

- [ ] Calculator works independently through an agent tool call.
- [ ] Simple general question answered directly; record actual tool behaviour.
- [ ] Multi-step question uses web search and then calculator.
- [ ] Invalid arithmetic (e.g. division by zero) does not crash the whole run.
- [ ] Tool call inputs and tool results are visible in terminal output.
- [ ] README includes actual, unedited sample logs.
- [ ] `.env` is not tracked by Git.
- [ ] GitHub repository is public and URL opens in an incognito browser.
